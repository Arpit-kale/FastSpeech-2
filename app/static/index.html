How it works

  1. Text frontend — numbers, dates and times are expanded; English uses CMUdict + POS-aware g2p_en, Telugu a rule-based akshara-to-phoneme converter.
  2. Encoder — 4 Feed-Forward Transformer blocks turn phonemes into hidden states.
  3. Variance adaptor — predicts each phoneme's duration, pitch and energy; the sliders scale these predictions.
  4. Length regulator + decoder — expands phonemes to frames and predicts an 80-bin mel spectrogram, refined by a PostNet.
  5. HiFi-GAN vocoder — converts the mel spectrogram to a 22.05 kHz waveform.

Durations were learned without forced alignment using a monotonic alignment search over a learned soft alignment (RAD-TTS style), which made Telugu support possible without an external aligner.
